Place licensed PXDL font files in this directory.

Expected file names:

- SuisseIntl-Regular.woff2
- SuisseIntl-Medium.woff2
- SuisseIntl-SemiBold.woff2
- SuisseIntl-Light.woff2
- SuisseIntl-Bold.woff2

The CSS also checks local installed fonts before loading these files.
The administrator dashboard uses Suisse Intl for both body and headings.
